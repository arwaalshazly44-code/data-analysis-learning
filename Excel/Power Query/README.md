## An Important Lesson I Learned

One of the most important things I learned in **Power Query** is that data should be structured properly before analysis.

* **Each column should contain one type of information.**
* **Each piece of information should be stored in its own column.**

Understanding this helped me know when to use **Pivot, Unpivot, and Transpose** to transform the data into the right structure for analysis.

This makes the data easier to clean, analyze, and use in Pivot Tables.
